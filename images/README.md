# Images folder

Drop project tile images here. The portfolio expects these filenames:

- `mirror.png`
- `emergency-incident-intelligence.png`
- `ai-debug-duck.png`
- `ec2-minecraft-neoforge.png`
- `puzzle-game.png`

**Recommended specs:**
- Aspect ratio: 16:9 (landscape, matches Netflix tile shape)
- Resolution: at least 800×450, ideally 1280×720
- Format: PNG (or JPG — just match the filename in `script.js`)

If a file is missing, the tile shows a fallback card with the project title — so the layout still works.
